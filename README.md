# Trabajo_Practico_Lenguajes_informaticos

Un trabajo donde de un sitio web ficticio de una ciudad para visitar,Este particulamente se centrara en la ciudad ficticia del videojuego "horizon zero dawn"

—————————————————————————————————————————————————————————————————————————————————————————————————————————————————————————

Contexto Historico General Ficticio:

La humanidad y el planeta entero perecieron a causa de la plaga Faro en el siglo XXI,una enjambre robotico militar autoreplicante extraodinario e inhackeable que consumia toda la biomasa como combustible,está se rebelo dejando de responder y empezo a consumir toda la biomasa en la tierra,a raiz de ello se creo el proyecto Zero Dawn, un sistema automatizado con un conjunto de IAs escondido en las montañas de las maquinas capaz de replicar la vida y desactivar la plaga de Faro.
El sistema estaba destinado para operar sin la humanidad ya que la plaga acabaria con la vida en la tierra en solo 15 meses y desactivar el enjambre llevaria alrededor de 50 años, luego restaurar la vida cual le llevaria siglos,lamentablemente se borro por delirios de un Ted Faro atormentado,inversor principal del proyecto Zero Dawn  y creador de la plaga Faro la base de datos APOLO que contenian todo el conocimiento de la humanidad,como consecuencia los seres que salieron incubadoras lo hicieron con ignorancia tanto de lo que sucedio como de conocimientos en general.
Una vez expulsados los jovenes-adultos de los centros de crianza con aprendizaje de jardin basico estos empezaron a formar las primeras tribus,desde estos hechos hasta el presente han pasado 700 años y cual de todas las tribus surgieron los Carjas,la más avanzada de todas que puede compararse con la civilizacion real de los romanos,los Carjas erigieron Meridian,la ciudad y centro urbano más avanzado en el solminio de cual aparte de su politica,economia,clases sociales destaca sobretodo su arquitectura.

Detalle importante de contexto: Para sostener el plan de recreacion de la vida en la tierra se creo un sistema de ingeneria con maquinas operando alrededor de la tierra creando,recolectando y fabricando recursos terminando en un ciclo sin fin pero estas se volvieron agresivas contra la humanidad desde "la locura de las maquinas" volviendose hostiles.

—————————————————————————————————————————————————————————————————————————————————————————————————————————————————————————

Proyecto web:

En este proyecto se busca evocar una pagina web turistica para que las tribus (extranjeros o turistas) a visitar el Reino Carja y el solmonio con enfazis en la ciudad de Meridian proveniente del videojuego "Horizon zero dawn" de 2017 ganadora de  varios premios siendo reconocido por su historia, dirección artística, mundo abierto y calidad técnica.

Herramientas utilizadas:
Visual Studio Code :Editor de codigo base

HTML:lenguaje de marcado encargado de estructurar las paginas web respetando una semantica preestablecida.

CSS: lenguajes de estilos visuales que personaliza la apariencia como su forma, color, fuentes de texto, tamaños, margenes y distribucion dentro la pagina.

Bootstrap:Framework de código abierto basado en HTML, CSS y JavaScript que proporciona componentes y estilos prediseñados para sitios web modernos, adaptables y responsivos de manera rápida.

Javascript: Lenguaje de programación que permite interactuar con elementos de las páginas web, como formularios, buscadores y actuar bajo ciertos valores segun el caso.
